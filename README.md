# Бэкенд для мобильного приложения "Соседи+"

## 🏗 Архитектура и База данных

- **Стек технологий:** `NestJS` (строгая архитектура), `TypeScript` (типизация без any), `Prisma ORM` (удобная работа с базой) и `PostgreSQL` (надежное хранение данных).

- **Умная модель Ledger (Журнал)**: Мы отказались от сложных подсчетов и таблиц долгов в пользу единой таблицы `Transaction`. Оплата — это плюс, долг — это минус. Баланс квартиры считается на лету простым сложением.

- **Связи:** Настроены строгие реляционные связи между Жильцами, Квартирами, Категориями, Общими расходами и Транзакциями.

## 🔐 Безопасность и Авторизация

- **JWT-токены:** Реализована ротация токенов (короткоживущий `Access` на 15 минут и долгоживущий `Refresh` на 30 дней) через стратегии `Passport.js`.

- **RBAC (Управление доступом на основе ролей):** Написан кастомный страж `RolesGuard`. Приложение четко разделяет:

- **ADMIN (Управдом):** может создавать расходы, начислять долги, вносить оплаты, регистрировать соседей и добавлять категории.

- **USER (Сосед):** может только просматривать сетку квартир, проверять свой баланс и смотреть прозрачную историю операций.

## ⚙️ Бизнес-логика (API Эндпоинты)

- **Квартиры (/apartments):** Отдают готовую сетку с высчитанными балансами. При запросе конкретной квартиры отдается подробная история операций (от новых к старым).

- **Общие расходы (/global-expenses):** Сердце системы. Управдом создает акт (например, "Ремонт крыши"), и сервер через безопасную транзакцию БД (`$transaction`) автоматически и поровну распределяет долг только по выбранным квартирам, игнорируя "проблемные".

- **Пользователи (/users/register-neighbor):** Удобный инструмент для Управдома, чтобы заводить аккаунты соседям и привязывать их к номерам квартир.
